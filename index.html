Termlar, df va idf

So‘rovni yozing — termlar, df va idf qayta hisoblanadi.

So‘rov
Hujjat matniga kiradigan maydonlar:

1) Termlar

2) df va idf

df(t) = t term uchragan hujjatlar soni, N = hujjatlar soni
idf(t) = ln( (N − df + 0.5) / (df + 0.5) + 1 )

3) Hujjatlar va term chastotalari (tf)

BIM — Binary Independence Model

Termlar binar (bor / yo‘q). Relevantlik ma’lumoti yo‘q: pt = 0.5, ut ≈ df/N.

RSV(d,q) = Σt∈q∩d ct ,  ct = ln( pt/(1−pt) · (1−ut)/ut ) ≈ idf(t)
So‘rov

BM25

BIM ga term chastotasi (tf) va hujjat uzunligi normalizatsiyasi qo‘shilgan.

score(d,q) = Σt∈q idf(t) · tf·(k₁+1) / ( tf + k₁·(1 − b + b·|d| / avgdl) )
