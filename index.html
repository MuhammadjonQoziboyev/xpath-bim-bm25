2) df va idf

df(t) = t term uchragan hujjatlar soni
idf(t) = ln( (N − df + 0.5) / (df + 0.5) + 1 )  (Robertson–Spärck Jones, musbat shakl)
N = hujjatlar soni

03BIM — Binary Independence Model

Relevantlik haqida ma’lumot bo‘lmaganda: pt = 0.5, ut ≈ df/N. Termlar binar (bor / yo‘q).

RSV(d,q) = Σt∈q∩d ct ,  ct = ln( pt/(1−pt) · (1−ut)/ut ) ≈ idf(t)

04BM25

BIM ga term chastotasi (tf) va hujjat uzunligi normalizatsiyasi qo‘shilgan.

score(d,q) = Σt∈q idf(t) · tf·(k₁+1) / ( tf + k₁·(1 − b + b·|d|/avgdl) )
